# PHPYAZ

PHPYAZ is a PHP extension for searching and retrieving records from Z39.50 servers using the YAZ toolkit.
It supports parallel searches across multiple servers, record retrieval, and index scanning.
It supports PHP 7.0 and later, including PHP 8.6.
